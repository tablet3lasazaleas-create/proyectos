# Biblioteca de proyectos

Catálogo público de las aplicaciones web que vamos creando.

## Aplicaciones

- [Nexo — gestor de proyectos](https://tablet3lasazaleas-create.github.io/proyectos/nexo/index.html): organiza proyectos y tareas.
- [Control de camiones](https://tablet3lasazaleas-create.github.io/proyectos/control-camiones/): distribuidores, camiones por placa, ingresos, egresos y conteo de camionadas.
- [Asistencia y pagos](https://tablet3lasazaleas-create.github.io/proyectos/asistencia/): control diario de entradas y salidas, horas extra y nómina semanal.

## Datos

Control de camiones comparte sus registros entre dispositivos mediante Supabase y permite el acceso solo a cuentas autorizadas. Consulta la [guía de Control de camiones](control-camiones/README.md) para configurar cuentas y migrar datos locales. Asistencia y pagos también comparte sus registros por Supabase y usa una lista independiente de cuentas autorizadas para proteger la nómina; consulta su [guía de instalación](asistencia/README.md). El código de este repositorio es público. Los próximos proyectos se guardarán en carpetas propias y se añadirán a esta lista y al [catálogo web](https://tablet3lasazaleas-create.github.io/proyectos/).
