# Biblioteca de proyectos

Catálogo público de las aplicaciones web que vamos creando.

## Aplicaciones

- [Nexo — gestor de proyectos](https://tablet3lasazaleas-create.github.io/proyectos/nexo/index.html): organiza proyectos y tareas.
- [Control de camiones](https://tablet3lasazaleas-create.github.io/proyectos/control-camiones/): distribuidores, camiones por placa y camionadas con material, ingresos y egresos.

## Datos

Cada aplicación guarda sus datos localmente en el navegador donde se usa; no se sincronizan entre dispositivos. El código de este repositorio es público. Los próximos proyectos se guardarán en carpetas propias y se añadirán a esta lista y al [catálogo web](https://tablet3lasazaleas-create.github.io/proyectos/).
